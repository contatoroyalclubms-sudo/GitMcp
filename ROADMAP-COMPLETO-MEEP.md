- **Framework**: Express.js
- **Database**: PostgreSQL (prod) / SQLite (dev)
- **ORM**: Sequelize
- **Cache**: Redis
- **Queue**: Bull/Redis

- **Framework**: React 18
- **State**: Redux Toolkit
- **UI**: Material-UI
- **Charts**: Chart.js
